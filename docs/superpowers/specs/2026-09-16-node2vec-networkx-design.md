# Node2Vec 第二步：构建 NetworkX 图

## 目标与范围

保留 `model/node2vec_step1_check_graph.py` 作为邻接矩阵检查脚本。新建 `model/node2vec_step2_build_networkx.py`，只把源域 Fold 1 的二值邻接矩阵转换为 NetworkX 无向图并检查结果。本步不做随机游走、嵌入训练，也不保存额外图文件。

## 数据流

1. 从 `SOURCE_STATION_ORDER.csv` 读取 104 个节点名称及顺序。
2. 从 `graph/fold_1/adjacency_binary.npy` 读取矩阵，检查其尺寸与节点数一致且对称。
3. 复制矩阵并把对角线清零；Node2Vec 随机游走不把自环当作普通边。
4. 创建 `nx.Graph`，先加入所有节点，避免孤立节点丢失；再逐一加入上三角矩阵中的边，避免无向边重复加入。
5. 输出图的节点数、边数和前几个节点的邻居，并与矩阵计算所得数量核对。节点名称维持 CSV 中的顺序。

## 错误处理与验证

输入文件不存在、节点名称重复、矩阵尺寸不符或不对称时，报出明确错误。自动化测试使用小型合成图，覆盖节点/边映射、去自环和孤立节点保留。随后从 `model/` 目录运行脚本，对实际 Fold 1 数据核对 104 个节点和 374 条无向边。脚本注释保留教学解释，简单 Python 表达式尽量写在一行。
